# moonalign-landing

https://moonalign.yjlab.io — MoonAlign 랜딩·계획 공유 페이지(`/p`)·앱 연결 파일(`.well-known`)의 **배포본**.

이 저장소의 파일은 손으로 고치지 않는다. 원본은 MoonAlign 저장소의 `marketing/landing/`(템플릿·문구)과
`scripts/demo/build_landing.py`이고, `scripts/landing/publish.sh`가 생성·검사한 결과를 여기에 복사·커밋한다.
README.md · CNAME · .nojekyll만 이 저장소에 직접 둔다.

호스팅: GitHub Pages(main 브랜치 루트), DNS: Cloudflare(`moonalign.yjlab.io` CNAME → `youngjaenah.github.io`).
