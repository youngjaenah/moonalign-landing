개인정보처리방침

MoonAlign은 회원 가입이 없고, 촬영 계획과 사진을 기기 안에서 처리합니다. 기능에 필요한 정보만 해당 서비스로 보냅니다.

시행일: 2026년 10월 6일

YJLAB(이하 "개발자")은 MoonAlign 앱(iPhone·iPad·Mac·Android, 이하 "앱")을 만들고 운영합니다. 이 방침은 앱이 어떤 정보를 쓰고, 어디로 보내며, 얼마나 보관하는지 설명합니다.

요약

  • MoonAlign에는 회원 가입·로그인이 없습니다. 이름, 이메일, 전화번호를 받지 않습니다.
  • 광고, 분석(사용 통계), 오류 보고 도구를 넣지 않았습니다. 사용 기록을 추적하거나 판매하지 않습니다.
  • 촬영 계획, 사진, 카메라 화면은 기기 안에서 처리합니다. 개발자 서버로 보내지 않습니다.
  • 지도, 지형, 비행기 위치 같은 기능을 위해 촬영지 좌표나 검색어를 해당 서비스에 보냅니다. 이 서비스들은 요청에 답하는 데에만 그 정보를 씁니다.
  • 개발자 서버는 지도 키 발급에 필요한 최소한의 정보(무작위 설치 ID 등)만 보관합니다.

기기 안에서만 쓰는 정보

정보쓰는 곳
기기 위치오늘 하늘 카드·위젯·천문 달력의 기준 위치, 지도의 현재 위치. 권한을 허용한 경우에만 쓰고, 백그라운드에서 위치를 추적하지 않습니다. 도시 이름을 찾을 때 좌표가 운영체제의 지오코딩 서비스로 갑니다(외부 서비스).
사진사진 확인 화면. 고른 사진 한 장만 열어 촬영 정보(EXIF의 시각·위치·방향·초점거리)를 읽고 기기 안에서 그립니다. 사진을 업로드하지 않습니다. Android는 시스템 사진 선택기를 써서 사진 전체에 접근하지 않습니다.
카메라·동작 센서AR 확인 화면. 카메라 영상과 기기 방향은 화면에 경로를 겹쳐 그리는 데만 쓰고 저장·전송하지 않습니다.
촬영 계획·내 랜드마크기기에 파일로 저장합니다. 동기화를 켠 경우 사용자 본인의 클라우드로 갑니다(동기화와 백업).
캘린더'캘린더에 추가'를 누를 때만 일정을 하나 넣습니다. 앱은 캘린더를 읽지 않습니다.
알림비행기 통과 알림 등은 기기 안에서 예약하는 로컬 알림입니다.
카메라 연결(Mac)비행기 모드의 자동 연사는 USB로 연결한 카메라에만 명령을 보냅니다.

외부 서비스로 보내는 정보

개발자 서버가 보관하는 정보

앱에 지도 키를 안전하게 나눠 주기 위해 개발자가 운영하는 서버(Cloudflare Workers)를 씁니다. 이 서버는 정품 앱인지 확인한 뒤 키를 발급하며, 다음만 보관합니다.

정보보관 기간
설치 식별자 — 앱이 처음 실행될 때 만든 무작위 ID(Android) 또는 Apple App Attest 키 ID(iOS·Mac)와 그 공개 키. 기기 고유 번호나 광고 ID가 아닙니다.앱 설치가 유지되는 동안(재등록 시 덮어씀)
요청 횟수 — 설치 식별자별·IP 주소별 하루 요청 수(남용 방지)최대 48시간(IP 주소별은 2시간)
구독 확인 결과 — Google Play 구매 토큰의 해시값과 상품·만료 시각(Android 구독자)최대 6시간

정품 확인을 위해 Apple(App Attest) 또는 Google(Play Integrity)의 확인 결과를 받고, Android 구독은 Google Play에 구매 토큰을 조회해 확인합니다. iOS·Mac 구독은 App Store 거래 서명을 서버에서 검증만 하고 보관하지 않습니다. 위치, 촬영 계획, 검색어는 이 서버로 가지 않습니다.

구매와 구독

앱 구매와 '해외 실사 3D 구독' 결제는 App Store 또는 Google Play가 처리합니다. 개발자는 결제 수단이나 청구 정보를 받지 않습니다. 구독 관리와 환불은 각 스토어에서 할 수 있습니다.

동기화와 백업

  • iCloud(iOS·Mac): 촬영 계획과 내 랜드마크는 사용자 본인의 iCloud Drive에, 본인 Google API 키는 iCloud 키체인에 저장되어 같은 Apple 계정의 기기끼리 동기화됩니다.
  • Google Drive(Android, 선택): 설정에서 켠 경우에만 촬영 계획과 내 랜드마크를 사용자 본인 Drive의 앱 전용 폴더에 저장합니다. 앱은 그 폴더 외의 Drive 파일에 접근하지 않습니다.
  • Android 백업: 기기 백업을 켜 두었다면 앱 설정과 촬영 계획이 Android 기본 백업에 포함될 수 있습니다. 키와 설치 식별자는 백업에서 뺍니다.

이 데이터는 사용자 계정에 저장되며 개발자는 볼 수 없습니다.

공유 링크

'공유'로 만든 링크에는 촬영 계획(타겟·촬영지 좌표, 날짜, 메모 등)이 링크 자체에 담깁니다. 이 부분은 주소의 # 뒤에 있어 웹사이트 서버로 전송되지 않지만, 링크를 받은 사람은 그 내용을 볼 수 있습니다. 공유할 상대를 확인해 주세요.

어린이

앱은 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 정보를 알면서 수집하지 않습니다.

선택과 삭제

  • 위치·사진·카메라·알림 권한은 기기 설정에서 언제든 끌 수 있습니다. 끄면 해당 기능만 쓸 수 없습니다.
  • 앱을 지우면 기기 안의 데이터가 삭제됩니다. iCloud·Google Drive에 동기화된 데이터는 각 서비스의 설정에서 지울 수 있습니다(Drive: 설정 → 앱 관리).
  • 개발자 서버의 설치 식별자 삭제를 원하면 아래 연락처로 알려 주세요. 회원 계정이 없으므로 앱의 시작 메뉴 → 도움말·정보 → 문의 메일 보내기로 보내 주시면(앱 버전·기기 정보가 미리 채워집니다) 찾는 데 도움이 됩니다.
